# Excuse Generator
 
A simple website that shows a random funny excuse when you click a button.
 
## How to use
 
1. Open the website.
2. Click **Give me an excuse**.
3. Read your excuse and click again for a new one.
## Built with
 
- HTML
- CSS
- JavaScript
